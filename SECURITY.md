# Security and project access

AI Process Collector is maintained in a private repository. Report security problems privately to the repository owner through your organization's approved internal channel. Include the affected release and reproduction steps using fictional information. Keep credentials, transcripts, document originals and database files out of reports and pull requests.

Contributions should be made through the authorized repository, using an existing runtime and synthetic test data. Run the Python and JavaScript suites described in the README before submitting a change. Third-party components keep the license and notices distributed with them. No additional redistribution permission is granted by this project note.
